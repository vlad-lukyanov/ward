WARD

Lightweight service watchdog for OpenRC. Monitors, auto-restarts, notifies. Лёгкий сторожевой сервис для OpenRC. Мониторит, перезапускает, уведомляет.

FeaturesВозможности

🔄

Auto-restartАвтоперезапуск

Detects failed services via rc-service and restarts them with configurable cooldown and attempt limits.Обнаруживает упавшие сервисы через rc-service и перезапускает с настраиваемым cooldown'ом и лимитом попыток.

🛡

Spiral protectionЗащита от спирали

Cooldown between restarts prevents infinite restart loops. Max restart limit per service.Задержка между перезапусками предотвращает бесконечные циклы. Лимит перезапусков на каждый сервис.

📱

Telegram

Notifications on restart, failure, and limit exceeded. Just add bot token and chat ID.Уведомления при рестарте, ошибке и превышении лимита. Добавьте токен бота и chat ID.

📊

Prometheus

Per-service metrics: status, restart count, failures, cooldowns. /health endpoint included.Метрики по каждому сервису: статус, количество рестартов, ошибки, cooldown. Эндпоинт /health.

⚡

Hot reloadГорячая перезагрузка

SIGHUP reloads config without restart. SIGUSR1 rotates logs without downtime.SIGHUP перезагружает конфиг без перезапуска. SIGUSR1 ротирует логи без даунтайма.

🖥

CLI

status, list, init commands. PID file, YAML config, logging to file or stdout.Команды status, list, init. PID-файл, YAML-конфиг, логирование в файл или stdout.

# 1. Create overlay structure sudo mkdir -p /var/db/repos/ward/{app-admin/ward/files,metadata} # 2. Create layout.conf sudo tee /var/db/repos/ward/metadata/layout.conf <<'EOF' masters = gentoo auto-sync = false repo-name = ward thin-manifests = true EOF # 3. Copy ebuild and files from repo cp app-admin/ward/ward-0.2.0.ebuild /var/db/repos/ward/app-admin/ward/ cp app-admin/ward/files/* /var/db/repos/ward/app-admin/ward/files/ # 4. Register overlay sudo tee /etc/portage/repos.conf/ward.conf <<'EOF' [ward] location = /var/db/repos/ward masters = gentoo auto-sync = false priority = 50 EOF # 5. Generate manifest and install cd /var/db/repos/ward/app-admin/ward sudo ebuild ward-0.2.0.ebuild manifest emerge app-admin/ward
sudo ./install.sh
# Download from GitHub Releases # https://github.com/vlad-lukyanov/ward/releases/tag/v0.2.0 tar xzf ward-v0.2.0-linux-amd64.tar.gz sudo install -m 755 ward /usr/local/bin/ward

OpenRC ServiceСервис OpenRC

sudo rc-update add ward default sudo rc-service ward start sudo rc-service ward reload sudo rc-service ward stop
